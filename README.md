# Web Application Security Lab

## 📌 Overview
Practical learning of common web application security vulnerabilities in a controlled lab environment.

## 🎯 What I Learned
- OWASP Top 10
- SQL Injection
- Cross-Site Scripting (XSS)
- OS Command Injection
- Authentication & Authorization
- File Upload Security
- Sensitive Data Protection
- Logging & Monitoring
- Cryptography Basics

## 🛠️ Tools Used
- Burp Suite
- OWASP ZAP
- Kali Linux
- DVWA (Damn Vulnerable Web App)
